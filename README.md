# Misión de investigación: SQL + Python + IA

Emma Choque Sandoval - Curso IA SomosF5

Repositorio con el código de la misión "SQL + Python + IA". Todo trabaja con una base de datos SQLite de práctica en memoria, con cinco películas ficticias (no hace falta descargar nada).

## Archivos

- `ejemplo_basico.py`: ejemplo mínimo y comentado. Crea la tabla `peliculas`, inserta cinco registros, ejecuta una consulta con `execute()` y recupera los resultados con `fetchall()` (Retos 2, 3 y avanzado A).
- `reto_b_con_errores.py`: programa con dos errores para detectarlos (reto avanzado B).
- `reto_b_corregido.py`: el mismo programa ya corregido.
- `reto_c_mini_analisis.py`: calcula la puntuación media con Python y con `AVG()`, busca la mejor película y cuenta películas por género (reto avanzado C).

## Cómo ejecutarlo

Hace falta Python 3 (el módulo `sqlite3` ya viene incluido):

```
python ejemplo_basico.py
```
